# signon 1.0.0

2026-11-15. The project is named `signon` from this version.

## New

- **Notifications** (feature `notify`): messages to people and channels - Slack, Teams,
  Telegram, a generic webhook, and email through the mailer.
- **Messages in six languages**: the API's error texts and the mail, each error with a code that
  is the same in every language (`SO-Ennn`).

## Changed

- The crate, its cookies (`signon_*`) and its error codes carry the new name.
